# Brent Oil Dashboard — Frontend & Backend Setup

Interactive dashboard for exploring Brent crude oil prices, the detected Bayesian change point, and researched market events.

## Architecture

- **Backend:** Flask REST API (`backend/app.py`) serving historical prices, change point results, and events data.
- **Frontend:** React (Vite) single-page app using Recharts for visualization.

## Running the Backend

```bash
cd backend
python app.py
```

Runs on `http://127.0.0.1:5000`. Endpoints:

| Endpoint | Description |
|---|---|
| `GET /api/health` | Health check |
| `GET /api/prices?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD` | Historical daily prices, optionally date-filtered |
| `GET /api/changepoint` | Cached Bayesian change point model results (from Task 2) |
| `GET /api/events?category=<name>` | Researched events dataset, optionally filtered by category |

**Note:** `/api/changepoint` reads a cached JSON file (`data/change_point_results.json`) generated by `notebooks/change_point_model.ipynb`, rather than re-running MCMC sampling on every request — this is a deliberate design choice for API responsiveness.

## Running the Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on `http://localhost:5173`. Requires the backend to be running simultaneously on port 5000 for data to load.

## Dashboard Features

- **Price chart** with the Bayesian change point marked as a solid vertical line, and all 16 researched events overlaid as color-coded dashed lines by category.
- **Stats panel** showing the detected change point date, credible interval, mean price before/after, and percentage change.
- **Date range filter** to zoom into specific periods.
- **Event category filter** (Geopolitical Conflict, OPEC Policy, Economic Shock, Sanctions/Policy, Market Event).
- **Events table** listing all events in the currently selected range/category.
